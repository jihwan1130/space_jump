# SPACE JUMP — 우주 점프

지구에서 출발해 행성에서 행성으로 점프해 나가는 **Orbit / Circle Jump** 장르의 웹 게임 프로토타입.
라운드는 무한히 이어지고, 스테이지가 올라갈수록 난이도가 계속 상승합니다.

의존성 없는 단일 HTML 파일(Canvas 2D)이라 `index.html`을 브라우저로 열기만 하면 바로 실행됩니다.

## 실행

```bash
# 그냥 파일 열기
start index.html

# 또는 로컬 서버로
npx serve -l 4321 .
```

## 조작

- **탭 / 클릭 / 스페이스** — 점프
- **M** 또는 우측 상단 아이콘 — 사운드 토글

## 게임 규칙

1. 우주선은 행성의 점선 궤도를 따라 공전합니다.
2. 점프하면 **우주선이 향한 직선 방향(행성 중심 → 우주선) 그대로** 발사됩니다.
3. 날아가다 다음 행성의 점선 궤도 안에 들어가면 자동으로 착지해 공전을 시작합니다.
4. 빗나가면 그대로 우주 밖으로 날아가 실패합니다. (벽에 튕기지 않습니다)
5. **목성(스테이지 4)부터는 아래에서 공간 붕괴가 차올라옵니다.** 멈춰 있으면 삼켜집니다.

실패 유형: `추락` · `궤도 이탈` · `우주 미아` · `소행성 충돌` · `행성 붕괴` · `공간 붕괴`

## 스테이지 / 난이도 곡선

행성 8개마다 스테이지가 오르고, 각 스테이지는 실제 태양계 순서를 따릅니다.

`지구 → 달 → 화성 → 목성 → 토성 → 천왕성 → 해왕성 → 명왕성 → 외계행성 → 심우주 N…`

스테이지가 오르면서 함께 변하는 값:

| 요소 | 변화 |
|---|---|
| 행성 크기 / 궤도 반경 | 점점 작아짐 |
| 자전(공전) 속도 | 점점 빨라짐 |
| 행성 간 거리 / 좌우 편차 | 점점 멀어짐 |
| 조준 표시선 | 지구(스테이지 1)에서만 표시 |
| 소행성 (궤도를 도는 장애물) | 스테이지 2부터 등장, 확률 증가 |
| 이동 행성 (좌우로 흔들림) | 스테이지 3부터 등장 |
| **공간 붕괴 (아래에서 차오름)** | **스테이지 4부터, 상승 속도 80 → 175px/s** |
| 붕괴 행성 (제한 시간) | 스테이지 5부터 등장 |

봇 시뮬레이션 기준 난이도 층위:

- 대충 하면 → 소행성에서 막힘 (중앙값 30점 부근)
- 소행성까지 피하면 → 공간 붕괴가 끝을 냄 (중앙값 75점, 스테이지 17까지 도달)

체크포인트(각 스테이지 첫 행성)는 크고 느려서 한숨 돌릴 수 있게 되어 있습니다.

## 카메라

착지한 행성이 화면 세로 78%(`CAM_ANCHOR`) 지점에 고정되어, 점프할 때마다 **직전 행성은 화면 밖으로 완전히 밀려납니다.**
카메라는 위로만 이동합니다. 공간 붕괴면은 화면 아래 `HAZARD_LAG`(270px)보다 더 뒤처지지 않아서
빠르게 올라가도 계속 따라붙습니다.

## 밸런스 튜닝

난이도 수치는 전부 `diff(stage)` 한 함수에 모여 있습니다. 여기 값만 바꾸면 곡선 전체가 조정됩니다.

콘솔에서 내부 상태에 접근할 수 있는 핸들도 열려 있습니다:

```js
window.__spacejump   // { state, jump, reset, diff, planetById, update, draw }
```

`update(dt)`를 직접 호출하면 화면 렌더링과 무관하게 결정론적으로 시뮬레이션할 수 있어,
봇을 붙여 스테이지별 난이도를 수치로 검증할 수 있습니다.
